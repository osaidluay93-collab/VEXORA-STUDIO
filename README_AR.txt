VEXORA STUDIO — النسخة الأولية 1.0

طريقة التشغيل:
1. فك ضغط الملف.
2. افتح مجلد VEXORA_STUDIO.
3. انقر مرتين على index.html.
4. استخدم أحدث Microsoft Edge أو Google Chrome.

الموجود حالياً:
- فتح الصور وتعديل السطوع والتباين والتشبع.
- إضافة نص ولون للنص.
- تنزيل الصورة بصيغة PNG.
- فتح الفيديو ومعاينته.
- تحديد بداية ونهاية مقطع وتصديره بصيغة WebM (يعتمد على دعم المتصفح).

مهم:
هذه نسخة أولية وليست بديلاً كاملاً عن CapCut. لا تتضمن حالياً مسارات متعددة أو انتقالات ومؤثرات متقدمة أو تصدير MP4. تصدير الفيديو يتم بسرعة التشغيل الفعلية وقد لا يعمل مع كل صيغ الفيديو أو كل المتصفحات. اترك الصفحة مفتوحة حتى ينتهي التصدير.
ملفاتك تتم معالجتها محلياً داخل المتصفح ولا تُرفع إلى خادم.
هذه ليست حزمة MSIX النهائية لمتجر Microsoft Store؛ يلزم بناء الحزمة واختبارها واستكمال متطلبات المتجر لاحقاً.
