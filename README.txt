VEXORA STUDIO — Simple Web Preview

1. Extract this ZIP.
2. Open your VEXORA-STUDIO repository on GitHub.
3. Choose Add file > Upload files.
4. Upload index.html from this folder (not the ZIP).
5. Commit changes.
6. In repository Settings > Pages, publish from branch main and folder /(root).

This is a simple image-design preview. It does not yet include video editing, accounts, cloud saving, or a public community gallery.
