VEXORA STUDIO — Windows / Microsoft Store preparation

هذه حزمة مصدر محسّنة لتكون قابلة للتثبيت كتطبيق ويب تقدمي (PWA). ليست حزمة MSIX نهائية، ولم تُرسل إلى Microsoft Store بعد.

الخطوات التالية للنشر:
1) استضافة محتويات مجلد VEXORA_STUDIO على موقع HTTPS عام.
2) فتح رابط التطبيق المستضاف وفحصه عبر PWABuilder: https://www.pwabuilder.com/
3) إنشاء حزمة Windows (MSIX) من PWABuilder واختبارها على Windows.
4) تجهيز صفحة المتجر ولقطات الشاشة وسياسة الخصوصية ومعلومات المطوّر.
5) يقدّم شخص بالغ طلب النشر عبر Microsoft Partner Center وفق شروط Microsoft الحالية.

مهم:
- لا توجد خدمة مجتمع/مشاركة سحابية مفعّلة في هذه النسخة.
- ملفات المستخدم تبقى محلية بحسب وظائف التطبيق الحالية.
- يجب اختبار التثبيت والتوافق وإكمال متطلبات المتجر قبل وصف التطبيق بأنه منشور أو جاهز نهائياً.
- لا تضع كلمات المرور أو مفاتيح Secret في ملفات التطبيق أو تشاركها.
